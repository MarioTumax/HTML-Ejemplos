Tipos de datos en MySQL

varchar

se usa para almacenar cadenas de caracteres. Una cadena es una secuencia de caracteres. Se coloca entre comillas (simples): 'Hola' .
El tipo "varchar" define una cadena de longitud variable en la cual determinamos el maximo El tipo "varchar" define una cadena de logitud variabe en la cual determinamo el maximo de caracteres. Puede gurdar hasta 255 caracteres. Para almacenar cadenas de hasat 30 caracteres, definamos un campo de tipo varchar(30).

int

Se usa para guardar calores numéricos entreros, de -200000000 a 200000000 aprocimadamente.
Definimos campos de este tipo cuando queremos representar, por ejemplo, cantidades.
